## Sobre o projeto

[O jogador deve coletar macacos de toca para ganhar. O jogo se passa em um local surrealista. O jogo inteiro é cinza]

## O que o projeto faz

- [O jogador movimenta o personagem usando as teclas WASD ou as setas.]
- [Ao encostar nos itens, eles desaparecem e o placar aumenta.]
- [Quando coleta todos os itens, aparece uma mensagem de vitória.]

## O que o projeto contém

- **Scripts:** [Camera.cs:Faz a camera acompanhar o player. PlayerMov.cs: Movimentação do player e sua pontuação. Rotator.cs: Faz o objeto girar]
- **Objetos principais:** [Player, Map, PickUp]
- **Recursos usados:** [CharacterController, Collider com Is Trigger, TextMeshPro.]

## Controles

- **WASD / Setas:** Movimentar o jogador.

## Como abrir

1. Baixe ou clone este repositório.

3. Clique em **Add** ou **Add project from disk**.
4. Selecione a pasta do projeto.
5. Abra o projeto usando a versão compatível da Unity.
